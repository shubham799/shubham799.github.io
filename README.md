# shubham799.github.io

Personal portfolio of Shubham Panwar, Lead Engineer.

**Live:** https://shubham799.github.io

Plain HTML, CSS and vanilla JavaScript. No build step: GitHub Pages serves the files in this repo's root as-is.

## Structure

```
index.html        page content (edit text here)
css/style.css     theme colours, fonts and layout
js/main.js        theme toggle, mobile menu, active nav link
assets/resume.pdf your resume (linked from the Resume buttons)
.nojekyll         tells GitHub Pages to skip Jekyll processing
```

## Run locally

Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000
# then visit http://localhost:8000
```
